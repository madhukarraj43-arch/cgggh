## 🛠️ Tech Stack

- **Frontend**: React 18
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS with custom iOS Liquid Glass extensions (`backdrop-filter`, specular highlights, fluid blob keyframes)
- **Icons**: Lucide React
- **Deployment**: Vercel ready (`vercel.json`)

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
